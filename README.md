# Logistics-Distribution-E-commerce

Project Overview
Design and implementation of a real-time data integration architecture focused on multichannel inventory synchronization (spanning Amazon FBA, Shopify, and physical warehouses) alongside automated freight quoting and commercial operations.

Business Challenge
E-commerce and distribution companies frequently suffer from stockouts or overselling due to a lack of integration between sales front-ends and internal control systems (WMS/ERP). Additionally, manual quoting processes involving multiple carriers slow down commercial responsiveness.

Technical Architecture & Implementation
Inventory Synchronization: Developed API-driven connectors that instantly update inventory levels across all sales channels the moment a transaction occurs.

Demand Tracking & Alerts: Integrated Power BI dashboards connected to the data pipeline to monitor key logistical KPIs, such as stock turnover, stockout rates, and reorder points.

Quoting Automation: Deployed automation bots that query carrier rate tables, calculate profit margins, and format commercial proposals automatically.

Key Technologies Used
Languages & Analytics: Python, SQL, DAX, Power Query

Visualization: Power BI

Integrations: Shopify APIs, Amazon FBA data structures, Webhooks

Results and Impact
Eliminated 100% of overselling incidents and out-of-stock discrepancies across channels.

Dramatically improved operational agility, reducing response times for complex freight quotes.

Provided centralized executive visibility over logistical performance and channel-specific margins.
